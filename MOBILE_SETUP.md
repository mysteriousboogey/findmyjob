# Find My Job on a phone

## Fastest setup

1. Open the ChatGPT mobile app.
2. Start a normal chat.
3. Send:

   > Load the Find My Job instructions from https://github.com/mysteriousboogey/findmyjob and start my job-search setup now. Use ordinary web search; do not require desktop installation.

4. When ChatGPT confirms the instructions are loaded, answer its first onboarding question.

That conversation is the mobile installation: keep it and return whenever you want another search. No computer, Python, Scrapling, or permanent plugin installation is required.

## Reusable mobile home

If **Dots** are available in the ChatGPT mobile app, create a Dot named **Find My Job** and send it the setup message above. Dots keep ongoing context and can be created entirely on a phone. If the account does not have Dots, continue using the original chat or paste [PORTABLE_PROMPT.md](PORTABLE_PROMPT.md) into a new chat.

## What may differ on a phone

Phone mode uses ordinary web search. It may verify fewer difficult pages than a computer running the optional Scrapling helper, but it must still complete onboarding, search, verify results, and use the same six-column output. Scheduling is offered only if the account supports real scheduled tasks.

The repository is private. ChatGPT must have access to it; otherwise use the portable prompt, which contains the core workflow without needing GitHub access.
